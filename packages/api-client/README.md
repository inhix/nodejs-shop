# @shop/api-client

Typed API client for the frontends. Types are generated from `@shop/contracts/openapi.json`
with openapi-typescript; requests go through openapi-fetch. See ADR 0007.

```ts
import { createApiClient } from '@shop/api-client';

const api = createApiClient({ baseUrl: 'http://127.0.0.1:3000' });
const { data, error } = await api.GET('/health/ready');
// data: Readiness on 200; error: ReadinessProblem on 503
```

`src/generated/schema.ts` is generated by `pnpm generate` (repo root) and committed. Never
edit it by hand.
